# Portadas

Portadas (1080 × 1920) de los reels de @dr.walterosorio.

Existe por una razón técnica: la API de Instagram acepta una portada propia
sólo como `cover_url`, es decir una URL pública que Meta descarga. No se puede
subir el archivo desde el disco como sí se hace con el video.

Estas imágenes son las mismas que Instagram muestra como portada de cada reel.

Las genera `scripts/marca/armar-portadas.py`. No se editan aquí.
